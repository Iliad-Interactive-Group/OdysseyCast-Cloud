Embeddable web components and plugins for radio station websites and third-party platforms.

## Notes

Plugins in this bucket are standalone embeds — they do not use the Next.js app framework. Each plugin is a self-contained build (vanilla JS or Web Component) deployable via CDN or direct embed.

Outlier standards and accepted integration patterns are tracked in [OUTLIER_PATTERNS.md](./OUTLIER_PATTERNS.md).
